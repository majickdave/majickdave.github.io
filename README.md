# My Jekyll Portfolio

Welcome to my newly revamped personal portfolio built with **Jekyll**! 🚀

## 📌 Overview
This project marks a major upgrade from my previous HTML-based portfolio. Now powered by **Jekyll**, this site is easier to maintain, scalable, and supports dynamic content like blog posts and projects.

## 🛠️ Features
- Built with **Jekyll** for static site generation
- Markdown-powered blog for easy content updates
- Responsive and mobile-friendly design
- Hosted on **GitHub Pages** for seamless deployment
- Customizable themes and layouts

## 🚀 Installation & Setup
If you’d like to run this project locally, follow these steps:

### 1️⃣ Clone the Repository
```sh
git clone https://github.com/your-username/your-portfolio.git
cd your-portfolio
```

### 2️⃣ Install Jekyll Dependencies
Make sure you have Ruby and Bundler installed, then run:
```sh
bundle install
```

### 3️⃣ Run the Development Server
```sh
bundle exec jekyll serve
```
Visit `http://localhost:4000` in your browser to view the site.

## 📄 Deployment
This portfolio is deployed using **GitHub Pages**. To update the live version, push changes to the selected branch:
```sh
git push origin main
```

## 🎨 Customization
- Modify `_config.yml` to update site settings.
- Add blog posts in `_posts/` using Markdown format.
- Customize styles in `assets/css/`.
